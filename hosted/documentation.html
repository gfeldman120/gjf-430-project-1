/api/getPokemon

GET

HEAD

Query Params

  • name (required): The name of the Pokemon to get

Returns

The JSON object for a specific Pokemon.

Example

Request: /api/getPokemon?name=Pikachu

Result: Some long array

/api/getElements

GET

HEAD

Query Params

  • name (required): The name of the Pokemon from which to get the elements
  • types (required if weaknesses=false): If true, get the types of the named Pokemon
  • weaknesses (required if types=false): If true, get the weaknesses of the named Pokemon

Returns

A JSON object containing arrays for the types and/or weaknesses

Example

Request: /api/getElements?types=true&elements=true

Result: Some long array

/api/getEvolutions

GET

HEAD

Query Params

  • baseName (required): The name of the Pokemon from which to get the evolutions
  • count (required): The maximum number of results to grab from the base named Pokemon

Returns

If evolutions exist, an array of all evolutions as JSON objects (NOT the shortened versions stored in the base named Pokemon)

Example

Request: /api/getEvolutions?baseName=Charmander&count=2

Result: Some long array

/api/addPokemon

POST

Query Params

  • name (required): The name of the new Pokemon
  • image (required): The image of the Pokemon
  • types (required): The types of the Pokemon, separated by commas
  • height (optional): The height of the Pokemon
  • weight (optional): The weight of the Pokemon
  • weaknesses (optional): The weaknesses of the Pokemon, separated by commas

Returns

If the name is unqiue, The JSON object of the newly created addPokemon
If the name isn't unique: Nothing as a 204 (overwrites existing Pokemon)

Example

Request: /api/addPokemon?name=MyPokemon&image=https://www.imageLink.com&types=Fire,Grass&height=5.3&weight=2.1&weaknesses=Water

Result: Some long array

/api/addEvolution

POST

Query Params

  • baseName (required): The name of the Pokemon that will acquire the evolution
  • evolutionName (required): The name of the Pokemon to add to the base named Pokemon, cannot already be an evolution of the base named Pokemon

Returns

The JSON object of the base named Pokemon, now with the evolution appended to next_evolution

Example

Request: /api/addEvolution?baseName=Pikachu&evolutionName=Rattata

Result: Some long array
